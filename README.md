# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` – главная страница;
- `catalog.html` – каталог товаров;
- `product.html` – карточка товара;
- `order.html` – страница оформления заявки;
- `delivery.html` – условия доставки;
- `about.html` – о нас;
- `contacts.html` – контактная информация;
- `css/style.css` – основной файл стилей;
- `css/responsive.css` – файл адаптивных стилей (ПЗ №12);
- `js/main.js` – файл JavaScript;
- `images/` – папка для изображений;
- `README.md` – описание проекта;
- `.gitignore` – список файлов, исключённых из Git.

## Используемые технологии

- HTML;
- CSS;
- JavaScript;
- Git;
- GitHub;
- GitHub Pages.

**Тема:** «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы разработан многостраничный HTML/CSS-сайт интернет-магазина.

Проект включает:

- главную страницу — `index.html`;
- страницу каталога — `catalog.html`;
- страницу карточки товара — `product.html`;
- страницу оформления заявки — `order.html`;
- страницу контактов — `contacts.html`;
- семантическую HTML-разметку;
- внешний CSS-файл;
- единую навигацию и якорные ссылки;
- карточки товаров, таблицу характеристик, форму заявки, модальное окно;
- CSS-переменные, состояния, Flexbox, Grid, БЭМ, позиционирование.

### Что добавлено в рамках КР1

- Созданы страницы `product.html` и `order.html`;
- добавлена таблица характеристик товара;
- добавлен бейдж «Хит» через `position: absolute`;
- приклеена шапка сайта через `position: sticky`;
- добавлена кнопка «Наверх» через `position: fixed`.

## CSS-архитектура

В проекте используются:
- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`.

## Использование Flexbox и Grid

В проекте используются:
- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.

## Контрольная работа №3 (Адаптивность)

**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

- Реализован подход **Mobile First**.
- Создан файл `css/responsive.css` и подключен ко всем страницам после основного `style.css`.
- Настроены медиазапросы под разные размеры экранов (мобилка, планшет, десктоп).
- Добавлены адаптивные изображения: используются теги `<picture>` и атрибуты `srcset` и `sizes` для карточек товаров.
- Адаптирована шапка (на мобильных меню в колонку, на ПК — в строку).
- Сетка карточек перестраивается от 1 до 3 колонок.
- Боковой фильтр в каталоге на мобильных устройствах уходит наверх, а на десктопе возвращается влево и становится `sticky`.
- Формы адаптированы: на мобильных кнопки занимают всю ширину и идут друг под другом.
- Таблицы характеристик и доставки обернуты в контейнер `.table-wrapper` для обеспечения горизонтального скролла на узких экранах.
